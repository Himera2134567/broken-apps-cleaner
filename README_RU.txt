BROKEN APPS CLEANER
Очистка пустых записей в разделе «Установленные приложения» Windows 10/11

ЧТО ДЕЛАЕТ ПРОГРАММА
--------------------
1. Проверяет стандартные разделы реестра, из которых Windows формирует список установленных приложений.
2. Находит записи, у которых команда удаления указывает на отсутствующий EXE-файл.
3. Показывает найденные записи в таблице.
4. Отображает ход сканирования, удаления и итоговый результат.
5. Перед удалением каждой записи создаёт отдельную резервную копию .reg.

ВАЖНО
-----
• Программа удаляет только выбранную запись из списка приложений.
• Реальные файлы и папки программ на диске она не удаляет.
• Размер, который Windows показывала рядом с пустой записью, обычно является старым сохранённым значением и не означает, что эти гигабайты реально заняты.

КАК ЗАПУСТИТЬ
-------------
1. Распакуйте ZIP-архив в любую папку.
2. Запустите BrokenAppsCleaner.exe.
3. Подтвердите запрос контроля учётных записей Windows.
4. Дождитесь автоматического сканирования.
5. Отметьте только те приложения, папки которых вы ранее удалили вручную.
6. Нажмите «Удалить выбранные записи».

РЕЗЕРВНЫЕ КОПИИ
----------------
После удаления на рабочем столе создаётся папка вида:
BrokenAppsCleaner_Backup_2026-07-17_01-30-00

В ней находятся:
• отдельные .reg-файлы для удалённых записей;
• result.log с результатом операции.

Чтобы восстановить запись, дважды щёлкните по соответствующему .reg-файлу и подтвердите импорт в реестр.

ИСХОДНЫЙ КОД И СБОРКА
---------------------
Проект не использует сторонние библиотеки.

Для повторной сборки нужен Go 1.23 или новее:
1. Установите Go.
2. Запустите build.bat.
3. Готовый BrokenAppsCleaner.exe появится в папке проекта.

ТЕХНИЧЕСКАЯ СХЕМА
-----------------
BrokenAppsCleaner.exe — небольшой нативный Windows-запускатель на Go.
Интерфейс и логика реализованы в локально встроенном PowerShell/WPF-скрипте.
При запуске ничего не скачивается из Интернета.
