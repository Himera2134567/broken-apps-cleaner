# Broken Apps Cleaner

Настольная утилита для Windows: находит записи в списке установленных приложений, у которых отсутствует EXE-файл деинсталлятора. Показывает кандидатов в таблице и позволяет удалить выбранные записи после резервного копирования соответствующих ключей реестра.

## Для чего нужна

После ручного удаления папки программы её запись может остаться в разделе «Установленные приложения». Утилита помогает проверить такие записи и убрать устаревшие сведения.

Размер в таблице берётся из сохранённых метаданных реестра. Удаление записи не освобождает указанные гигабайты и не удаляет файлы программы.

## Возможности

- Проверка веток деинсталляции HKLM для 64- и 32-битных приложений и ветки текущего пользователя HKCU.
- Разбор команд удаления, раскрытие переменных окружения и проверка EXE по абсолютному пути или через `PATH`.
- Таблица с названием, версией, сохранённым размером, областью установки и отсутствующим деинсталлятором.
- Выбор отдельных записей, выбор всех, сброс выбора и подтверждение удаления.
- Отдельная резервная копия `.reg` перед удалением каждого ключа. При ошибке экспорта этот ключ не удаляется.
- Индикатор выполнения, журнал операций и открытие папки резервных копий.

## Запуск без Python и виртуального окружения

1. Скачайте `BrokenAppsCleaner.exe` и `SHA256.txt` из [релизов](https://github.com/Himera2134567/broken-apps-cleaner/releases).
2. При необходимости проверьте контрольную сумму: `Get-FileHash .\BrokenAppsCleaner.exe -Algorithm SHA256`.
3. Запустите EXE и подтвердите запрос прав администратора.
4. Проверьте результаты автоматического сканирования, отметьте заведомо устаревшие записи и нажмите «Удалить выбранные записи».

Поддерживаемая среда: **Windows 10/11 x64** со штатными Windows PowerShell и WPF. Скрипт встроен в EXE; Python, venv и сторонние библиотеки не нужны. Для Linux и macOS этот EXE не подходит. Опубликован исходный EXE из предоставленного архива; цифровой подписи у него нет.

## Резервные копии

На рабочем столе создаётся папка `BrokenAppsCleaner_Backup_<дата и время>`. В ней находятся экспорты `.reg` и `result.log`. Для восстановления записи проверьте и импортируйте соответствующий `.reg`-файл. Сохраните резервные копии до проверки результата.

## Как устроен проект

| Файл | Назначение |
| --- | --- |
| `main.go` | Запускатель на Go. Встраивает PowerShell-скрипт, подготавливает временную папку, запускает скрипт и убирает временные файлы после завершения процесса. |
| `cleaner.ps1` | Интерфейс WPF, повышение прав, поиск записей, разбор команд удаления, резервное копирование и удаление выбранных ключей. |
| `go.mod` | Имя модуля и версия Go; сторонних Go-зависимостей нет. |
| `build.bat` | Сборка Windows x64 GUI-приложения без CGO. |
| `tests/smoke.ps1` | Изолированные проверки разбора команд, определения существования EXE и вспомогательных функций; реестр не изменяется. |
| `SHA256.txt` | Контрольная сумма первоначального EXE. Для новой сборки нужно вычислить новую сумму. |
| `README_RU.txt` | Первоначальная инструкция из архива. |

## Сборка и проверки

Для сборки нужен Go **1.23 или новее**. На Windows запустите `build.bat`. Скрипт `cleaner.ps1` будет включён в новый EXE; после изменения скрипта требуется пересборка.

Проверки без запуска интерфейса и изменения реестра:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\smoke.ps1
```

При подготовке публикации проверены синтаксис PowerShell, вспомогательные функции, SHA-256 исходного EXE, формат Windows x64 GUI и побайтовое совпадение встроенного скрипта с исходником. Интерфейс с правами администратора и удаление ключей не запускались. Новая локальная сборка не выполнялась: Go SDK отсутствовал.

## Ограничения

Отсутствие EXE — эвристика: причиной может быть перемещённый деинсталлятор или отключённый диск. Команды без распознаваемого `.exe` пропускаются. Ветка HKCU относится к учётной записи, под которой работает повышенный процесс. Перед удалением нужно проверить каждую запись. Утилита не восстанавливает программы, не проверяет их на вирусы и не очищает файлы на диске.
